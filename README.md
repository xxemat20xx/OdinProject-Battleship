# Battleship Game

A web-based implementation of the classic Battleship game, built as part of [The Odin Project]([https://www.theodinproject.com/](https://www.theodinproject.com/lessons/node-path-javascript-battleship)) curriculum. This project utilizes modern JavaScript practices, Webpack for module bundling, and Jest for testing.

## Features
- Classic Battleship gameplay with a 10x10 grid.
- Player vs. AI opponent.
- Random ship placement for AI.
- Interactive UI built with vanilla JavaScript.
- Test-driven development using Jest.

## Technologies Used
- JavaScript (ES6+)
- Webpack
- Jest
- ESLint & Prettier
- ChatGPT & GitHub Copilot
